# 4U Mobile MVP

一个面向手机浏览器的兴趣活动社交 MVP。活动支持双人同行与多人小组，首页以双列信息流展示真实活动和关联活动的人物卡。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

启动开发服务器后可运行交互与响应式检查：

```bash
npm run test:smoke
npm run test:responsive
```

## 当前能力

- 首页“推荐 / 活动 / 话题”两级菜单
- 双列四卡活动流与筛选内容
- 首页、寻觅、消息、我的四个底部页面
- 活动详情、收藏、报名确认、候补与发起活动交互
- 双人同行和多人小组两种关系场
- 使用浏览器本地存储保留收藏与报名状态
